## 项目分析：Lotterymcp-P3
- 定位：排列3（P3）历史数据 + MCP 接入 + 本地确定性分析工具。明确**非中奖预测**，强调可复现、无未来数据泄漏。MIT 许可，v0.7.0。
- 架构：npm workspaces monorepo，5 个包：
  - `lotterymcp-core`（packages/core，~4260 行）：核心。pl3-store.ts(2320) SQLite 档案/冲突/快照/GC；pl3-prediction.ts(872) 预测+walk-forward 回测；pl3-experiments.ts(948) nested walk-forward 评估器；pl3-features.ts(278) As-of 特征；index.ts(842) 类型/MCP 客户端/provider。
  - `lotterymcp-server`（mcp-server，236 行）：MCP stdio 服务，暴露 5 工具 latest/history/periods/summary/predict。
  - `neuxnbcp`（cli，1666 行）：主 CLI，自定义参数解析（非 commander）。命令：serve/init/doctor/login/predict(=analyze)/sync/data/experiment/ops + 交互菜单。
  - `lotterymcp`（nbcp）：发布 bin 包装（638B）。
  - `lotterymcp-web`（web，~830 行）：中文只读 SPA 研究台（总览/日报/回测/数据质量/运行状态）。
- 数据：remote（NEUXSBOT Token）/ official（本地公开数据无 Token）双模式。SQLite 分层存 raw/observation/conflict/snapshot，保留 23 个真实历史冲突做隔离。预测账本 JSON 状态 pending/provisional/confirmed/disputed。
- 实验：nested walk-forward，3 评估器（uniform-theory / random-monte-carlo / weighted-frequency-v1），冻结区仅一次显式评估。相同 spec+snapshot+code+seed → 同实验 ID 与报告哈希。
- 部署：Docker Compose + SSH 隧道（默认）/ 公网 auth；`ops serve-reports` 提供只读 SPA；企业微信 webhook 通知。
- 测试：tests/ 下 11 个 .mjs 测试文件齐全。
- **环境风险**：package.json engines 要求 node >=24 <25，但本机 managed node 为 v22.22.2；构建需切换 system 24.14.0（或 install_binary node 24）。npm 包管理要求 npm@11.11.0。
- 当前 git 干净，最新提交 feat: 新增排列3中文研究台（2026-07-21）。

## 关键部署/构建 gotcha（重要）
- **前端构建不会自动更新线上站点**：`vite build` 只产出 `packages/web/dist`，但 `ops serve-reports` 实际读取的是 `packages/cli/dist/web/`（webAssetsDir = dirname(import.meta.url)/web）。必须用官方复制脚本 `node scripts/copy-web-assets.mjs` 把 web/dist 同步到 cli/dist/web（根 `npm run build` 的最后一步）。漏掉这步 → 服务器一直喂旧构建，用户刷新多少次都看不到改动。
- 服务器按请求实时读磁盘（`await readFile` + index.html `no-store` + 资源 content-hash），**改前端后只需浏览器硬刷新，无需重启服务**。

## 「开奖号码没有更新」根因与修复
- 根因：数据库 `draws` 表最新确认开奖停在 **26190(2026-07-19, 5,5,4)**，今天 7/21，26191+ 新开奖从未同步进库；且总览 `currentSettlement` 只是一直 `pending`、无 actualNumbers → 页面"开奖号码: 暂无"。

- 用法（务必用 Windows 绝对路径设 dataDir，避免 Git Bash `$(pwd)` 拼出 `D:\d\...` 错路径）：
  `LOTTERYMCP_DATA_DIR="D:/as-workplace-cups-2026/Lotterymcp-P3/.lotterymcp-data" "C:/Program Files/nodejs/node.exe" packages/cli/dist/index.js data sync --limit 60`
- 结果：记录 7665→7666，新增 **26191(2026-07-20, 0,6,9)**，并**自动结算 1 条预测**（settlement 现含 actualNumbers [0,6,9]、status provisional、winningTickets 0、profit -20）。overview 接口实时读盘，刷新即见。
- 官方源可达：`https://www.lottery.gov.cn/zst/pls/`（lottery-gov-cn）与 `https://www.zhcw.com/kjxx/pl3/`（zhcw）均 HTTP 200。
